## 1.17.0 — 2026-10-09 (release R2026.18, deep annotation of every project)
* **Deep per-sample annotation of all 2,837 gut projects.** Every project was re-read from every source we can reach: all BioSample attributes (not only the mapped keys), sample titles / aliases / library names decoded into subject, time point, group and arm with two independent reasoning-model replicates that must agree (`gut_r1_deep_v1`), supplementary tables joined on sample, run, alias or subject identifiers (`gut_r2_deep_v1`), article body tables (`gut_r3_tables_v1`), and cohort-wide statements from newly linked papers (`gut_r3_newlink_v1`, `gut_r4_newlink_v1`). New values fill gaps only (never replace an equal or higher-ranked route). Sample coverage, 1.16.0 → 1.17.0: subject id 34.3 → 54.2 %; time point 13.5 → 30.0 %; exact age 26.3 → 28.6 %; sex 30.8 → 32.8 %; health condition 39.6 → 48.3 %; BMI 8.4 → 9.0 %; antibiotics 16.9 → 19.4 %; collection date 62.9 → 74.4 %; intervention arm 3.5 → 8.4 %; medication 0.7 → 1.6 %; diet 0.7 → 2.5 %; smoking 0.8 → 2.1 %. Where a new value and a published one both exist they agree for sex 99.9 %, country 99.8 %, exact age 98.9 % (± 15 days / 5 %), BMI 100.0 % of 141,369 / 448,327 / 116,791 / 39,208 compared samples. Evidence for every value is in `gut_sample_determinations` (evidence_source / locator / quote / parse_note).
* **Per-project source flags** (`gut_studies.src_archive`, `src_abstract`, `src_fulltext`, `src_supplement`, `src_external`, `src_contribution`, `src_expert` = used / checked / none, with `src_detail` JSON). Current counts — archive {'used': 2751, 'checked': 115}; abstract {'checked': 1622, 'used': 928, 'none': 316}; full text {'none': 1002, 'used': 984, 'checked': 880}; supplementary tables {'none': 1313, 'checked': 1239, 'used': 314}.
* **Paper links:** 466 new study × paper links for 401 projects that had none (accession search in Europe PMC full text and NCBI BioProject links, then title / description search judged by a reasoning model; `registry_study_papers.source = paper_search_verified`).
* **Scope corrections from the deep pass:** a catalog-wide BioSample host / organism scan removed 7,150 non-human, environmental and mock-community samples (`config/sample_exclusions.csv`, reason host_nonhuman / other, with the attribute quoted); 18 projects leave the catalog because no human gut sample remains or because their runs are 16S amplicon data deposited as metagenomes (PRJDB19255, PRJEB39960, PRJEB70509, PRJNA1155655, PRJNA1190698, PRJNA1209134, PRJNA1213876, PRJNA1245131, PRJNA1305438, PRJNA1433968, PRJNA1472735, PRJNA1514052, PRJNA428537, PRJNA450709, PRJNA596121, PRJNA769748, PRJNA804967, PRJNA976196; `config/registry_overrides.yaml`, stage curator_audit).
* **Model-written short titles (≤ 60 characters) and one- or two-sentence descriptions** for every project (`gut_studies.short_title`, `short_description`, `short_description_model`), from the archive record, the linked abstract and the curated sample facts; labelled as machine-written on the site.
* **Known limits:** Europe PMC delivered supplementary archives at roughly 20–600 KB/s during this pass, so many supplements were not read (flag `src_supplement = none`; listed on the Contribute page under "supplementary tables not accessible to us"); PDF-only supplements are not parsed; medication / diet / lifestyle attributes are mostly finer-grained than the vocabularies and stay unmapped.
* **Site:** project pages and every page header redesigned in the home-page style; per-project source checkmarks; at-a-glance panel with a globe of sample origins, depth and timeline sparklines; field coverage lists only fields the project has; sample tables load client-side with every metadata column the project has; Project sheet with narrow columns, short titles, source columns and filter; Contribute filters for missing supplements / full text.
