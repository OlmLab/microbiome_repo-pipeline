## 1.19.1 — 2026-10-10 (release R2026.24, external annotation of the content-filter gap projects)
* **Owner-run external annotation, verified on ingest.** The 706 projects whose R2026.23 subject-id / relatedness batches were stopped by the content filter were annotated outside the pipeline by the owner (two independent readings per project with claude-haiku-4-5 and claude-sonnet-5; orchestration claude-opus-5) using the bundle `external_annotation_R2026_23.zip`. On ingest every row was re-checked: catalog sample, project, gut site, no existing subject_id, and every quote re-fetched from the cited source (ENA description, Europe PMC abstract / full text, BioSample attributes, sample names). A first bundle quoted the catalog's own model-written short descriptions; those 2,707 rows were rejected and the bundle rules now forbid it. QA reports: `data/inputs/gut/design/logs/external/`.
* **subject_id:** 46 projects gain ids (4,126 generated one-sample-per-person, 18 single-subject, 72 from BioSample attributes, 46 decoded from sample names + 29 timepoint labels); coverage 73.9 % → 74.6 %. Three projects rejected on ingest (PRJNA272371, PRJNA386422, PRJNA311208); PRJNA850529 (922 ids from a supplementary table) is held until Europe PMC serves the file for re-verification.
* **Merged ids split:** PRJEB108450 published the household code as subject_id for 3,660 samples (now host_subject_id; the household code becomes family_id) and PRJNA1086951 an arm × timepoint code (e.g. `Control_BL`) for 637 samples (now the 213 person ids from the library names). Both projects are now longitudinal.
* **Relatedness and design:** family / household fields for 8 more projects (6,100 values); 500 study-design rows and 107 relations (77 FMT donor_of, 28 twin pairs, 1 partner). Projects with a relatedness design 281 → 342; relatedness groups 5,858 → 6,775; longitudinal status unknown 373 → 199.
