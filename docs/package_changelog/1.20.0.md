## 1.20.0 — 2026-10-12 (release R2026.25, every pass on every project)
* **Every applicable annotation pass has now run on every project.** New package table `gut_pass_coverage.csv` lists, per project, whether full text, abstract, interventions, deep per-sample, supplementary tables, subject_id and study design ran; the release fails if a pass never ran without a recorded exception (7 exceptions, all subject coverage lowered by withheld contradictory ids). Gap-fill waves: full text (R3 + R3b) for 150 + 120 projects, abstracts (R4 + R4b) for 99, interventions for 58, supplementary tables for 80 + 148 retries + 505 projects whose supplements Europe PMC could not serve (now read from the PubMed Central open-access bucket), subject ids for 5 and study design for 8 projects; 22,984 new per-sample values from the bucket supplementary pass alone.
* **Self-contradictory metadata is withheld (red ! badge).** When two sample-level sources give incompatible values (sex, country, antibiotics yes/no, ages more than 30 d and 20 % apart, BMI more than 2 apart, healthy control vs a disease) or one subject id's samples disagree on sex, neither value is published; both sides are in the new `gut_metadata_contradictions.parquet` (8,853 rows, 8,303 samples, 140 projects; new gut_studies columns `n_contradicted_samples`, `contradiction_summary`).
* **Scope: 95 projects moved out of the shotgun catalog.** Projects whose median run is under 50 Mbp were read twice independently; the 95 that both readings call amplicon (78), targeted / enriched (16) or not reads (1) are owner decisions in config/registry_overrides.yaml (the registry keeps them with the reason). Catalog: 2,893 to 2,798 projects, 588,558 to 573,001 samples.
* **Pooled BioSamples split by library.** The lane-suffix rule no longer strips library numbers (G15-003-669 was read as lane 669), and a library sequenced in several runs is one sample: 40 BioSamples became 2,928 library units in 35 projects (PRJNA361402: 868 runs under one BioSample, now 861 samples).
* **Longitudinal timing.** Bare-number timepoints take a unit from the stated schedule (23 projects) and a visit-code timing pass mapped 616 visit codes to quoted day offsets (155 projects, 27,341 samples; axis `timepoint_mapped`). Longitudinal projects with a resolved timeline: 542 to 635. One timing batch (100 projects) was stopped by the content filter and not retried.
* **Site:** home-page globe (click a country to open its projects), redesigned Contribute table, relationship graphs for every family / setting / explicit relation, intervention **I** marker (solid = per-sample arms resolved, 202 of 913 intervention projects) with arm diagrams by trial design, solid / dotted L, R and I markers, red ! for contradictions, shallow runs shown in Mbp instead of 0.00 Gbp, and Atlas › Figures (the six resource-paper figures) replacing Observations.
