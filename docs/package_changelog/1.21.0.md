## 1.21.0 — 2026-10-20 (release R2026.26, controls, access flags, paper-link audit)
* **Control samples are marked.** New gut_sample_metadata_wide column `sample_type` (specimen | negative_control | mock_community | positive_control | synthetic_community), detected from sample titles, library names, isolation sources and scientific names (`catalog.scopes.controls`, `config/sample_types.csv`). Controls no longer inherit cohort-wide values (age, sex, condition …) or a gut-site / life-stage class; new gut_studies column `n_control_samples`. Defined communities from environmental sources (rhizosphere experiments inside gut projects) are removed. "Mock FMT", sham and placebo samples are human specimens and are never marked.
* **Metadata behind an access application.** New gut_studies columns `metadata_access` (open | partly_controlled | controlled), `metadata_access_system`, `metadata_access_study`, `metadata_access_url`, from the dbGaP studies named in NCBI BioProject records (18 projects, e.g. TEDDY phs001443 / phs001442). `controlled` = the public records carry neither age nor health condition. Site: an **A** tag and an explanation with the application link on the project page.
* **Paper-link audit.** Every link labelled "generated the data" only because the paper was the one paper mentioning the accession (2,570 links with open full text) was re-read from the passages that mention the accession: 640 were re-use (meta-analyses, tools, validation cohorts) and are now `cites_accession`, 41 are `unsure`. Authors are credited only through data-generating papers; author corrections in `config/author_overrides.csv`.
