## 1.22.0 — 2026-10-20 (release R2026.27, read-level amplicon check)
* **Reads, not labels, decide amplicon vs shotgun.** `scripts/read_peek.py` downloads only the first ~150–400 kB of a run's FASTQ from ENA and checks the first reads: amplicon libraries start nearly every read with the same primer (share of distinct 20-nt read starts 0.01–0.1, 16S 515F/341F/27F primers on most reads); shotgun reads start anywhere (0.7–1.0). Results for every checked run: `data/inputs/registry/read_check_r2026_27.csv` (pipeline repo).
* **8 projects excluded in R2026.25 return with their shotgun samples.** The R2026.25 shallow-run screen judged projects by their median run, so mixed deposits (a few deep shotgun runs next to many 16S runs) were excluded whole: PRJEB77729, PRJEB37883, PRJNA746322, PRJNA767648, PRJNA1171148, PRJNA763692 (shotgun runs next to assembled genomes uploaded as reads), PRJNA324581 and PRJNA540073 (shotgun next to targeted capture). Their overrides are now `assay: mixed`; the amplicon / assembly samples are excluded per sample.
* **Amplicon samples removed from included projects.** Samples whose runs are all shallow (< 50 Mbp) were read-checked in every project where a 2-run screen found amplicon reads: 4,402 samples in 78 projects are amplicon (distinct read starts < 0.2 or a 16S primer on > 30 % of reads) and are excluded (`config/sample_exclusions.csv`, reason `assay_amplicon`, the read statistics as evidence). Borderline runs (0.2–0.3) and runs whose reads could not be read are kept.
