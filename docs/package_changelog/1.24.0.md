## 1.24.0 — 2026-10-23 (release R2026.29, read check rebuilt)
* **The read check that decides shotgun vs amplicon was rebuilt** (`scripts/read_check16s.py`). The R2026.27 check looked only at how varied the first ~1,000 read starts were; that also flags duplicated shotgun files, files whose first reads are N-masked (human reads removed), poly-A reads, colour-space reads and adapter dimers, and it called some 12-65 Gbp shotgun runs amplicon. The new check follows PARTIE (Torres et al. 2017, *Bioinformatics* 33:2389), whose decisive feature is the share of reads that align to 16S rRNA genes:
  * ~4,000 usable reads per run (N-masked, colour-space and homopolymer reads removed; reads deeper into the file when the start is masked), aligned with minimap2 to NCBI RefSeq 16S (27,646 genes);
  * **16S amplicon**: >= 50 % of reads align to 16S (16S amplicons: ~99-100 %; shotgun stool: median 0.2 %);
  * **other targeted amplicon** (ITS, other genes): ITS primer in >= 10 % of reads, or one 20-nt read start in >= 15 % of reads (shotgun runs > 1 Gbp: median 0.1 %, 99th percentile 13 %);
  * **adapter dimers** (failed library): >= 50 % of reads carry an Illumina adapter;
  * **shotgun**: < 5 % 16S and no dominant read start; anything else is *unclear* and left as it is.
* **92 samples reinstated** (4 projects: PRJNA1490646 66, PRJDB41979 22, PRJNA947616 2, PRJNA1099775 2) that R2026.27 had excluded as amplicon.
* **5,470 amplicon samples excluded** in 55 catalog projects (5,389 of them 16S by reads). 32 projects turned out to be amplicon-only and are marked `amplicon_misfiled` in the registry. Samples that have both amplicon and shotgun runs stay.
* Evidence for the 4,283 remaining R2026.27 read exclusions now quotes the new statistics. Run-level results: `data/inputs/registry/read_check_r2026_29.csv` (25,725 runs).
* Known limit: targeted amplicons of diverse genes whose reads do not share starts (for example gene-targeted sequencing across many species) look like shotgun to this check.
