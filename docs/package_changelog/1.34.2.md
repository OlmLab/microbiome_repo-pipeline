# Package 1.34.2 (R2026.43)

A site release. No sample, project or value was added, changed or retired: the data tables are those of 1.34.0 and 1.34.1.
What changed is the text of the site and of the package documents, after an external review of every page (617 findings and
96 proposals to cut or merge; 641 of the 713 were in scope for this release, the rest concern the structure of the site or
the data and are kept for later).

## Site

- **One word per thing.** The unit of the catalog is a "project" wherever a visitor reads (page addresses under `studies/`
  and the column `study_accession` keep their names; the registry still lists archive "studies"). The four ways a value can
  have been obtained are named in words — archive record, supplementary table, paper text, abstract — in place of the codes
  R1 to R4, in tables, legends, badges and the API descriptions (the `route` column of the tables keeps its codes). Words left
  from earlier phases of the resource (infant extension, universe, slice, verdict, determination, Atlas) are gone from page
  text.
- **Shorter pages.** Fields no longer repeats the data dictionary (it links to it); Scope links to the list of human projects
  left out instead of printing it; Contribute shows the first rows of the worklist and loads the rest on request; repeated
  "About this page" boxes, document lists and release notes are printed once.
- **Removed.** The Figures page and the observation cards (both redirect to the Taxon explorer); five reports from the
  infant phase of the resource under `docs/` (four of them remain files of the data package); collections whose rule
  matches no sample in this release (their addresses forward to the collections index).
- **Downloads.** The tables of the infant phase and the build files of the package are no longer listed or hosted on the
  site; they are in the package zip on GitHub and Zenodo, as before. The page says so.
- **Profile coverage and quality** (`atlas/measures.html`, formerly "Profile measures") is in the Insights menu; it is
  recomputed in every release.
- **Taxon map** (`atlas/index.html`): the page data are recomputed from the current community profiles. Until this release
  the map showed the profiles of September 2026 (306,165 samples in 1,905 projects, Sandpiper 2.0.0); it now shows 367,485
  samples in 2,754 projects and 114 countries (Sandpiper 2.0.1), and the page names the release and package it was computed
  from. The Taxon explorer was recomputed on this package as well. VANISH / BloSSUM and the replication page keep the
  results of package 1.34.0 and say so.
- **API.** `api/by-condition/` has one file per code of the health-condition vocabulary that has samples. The files that
  were named after free-text condition descriptions are gone (several of their addresses could not be fetched); the free
  text is still on every project record. The `<meta>` tags of every page are named `repo-…` instead of `catalog-…`.
- Statements that no longer held were corrected or removed, and numbers that disagreed between pages now come from one
  computed value each. No page address changed.
- The built site is 839 MB (945 MB in R2026.42).
- The result was read once more by an independent reviewer before publication, and what that reading found was fixed.

## Package documents

- `README.md`: the row counts of the file table are read from `VERSION.json` instead of being maintained by hand; the
  citation follows the form used on the site; pointers to reports that are no longer site pages name the file in the package.
- `DATA_DICTIONARY.md`: a contents list, and a first heading that says which tables the opening section describes.

## Not done in this release

- The structure of the site (menus, merging of sections, new addresses) was out of scope.
- Mapping free-text health conditions to vocabulary codes is data work for the next release.
- Findings that concern a value in the data (a project summary, a reason label, the rule of a collection) are listed for the
  next data release.
