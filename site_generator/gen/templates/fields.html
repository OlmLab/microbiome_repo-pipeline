Health-condition vocabulary

Codes come from archive attributes and supplementary tables — by rule where the wording is unambiguous, otherwise by a language model reading each distinct attribute value — and from papers only when every sequenced person shares the condition. unknown is a code in its own right: it is recorded where a source states that the condition is not known.

Confidence

{# R2026.44: the confidence text is the Audit chat's, from the blind re-derivation audit of release R2026.41 (data package 1.34.0). Its numbers are that audit's and are printed as it reported them, with the package they were measured on; they are NOT recomputed per release. Everything below the calibration table — the share of values of each source in each band — is computed from the package this site is built from, as before. #}

Confidence is a tier set by the engine that produced the value. It orders values by reliability; it is not a probability. We checked it in a blind audit of release R2026.41 (data package 1.34.0): 2,400 values were drawn at random within field, source type and confidence tier, and an independent reader derived each value again from the cited source without seeing ours. Disagreements were read again, the last time with both values in view. 2,204 values could be judged.

Shares are weighted to the catalog, with 95 % intervals. “Not confirmed from the cited source alone” means the reader, given only the cited text, would not have recorded the value. It covers cohort-wide statements applied to every sample of a project, time points and groups decoded from sample names, regions worked out from coordinates, and subject identifiers generated where a project has one sample per person. Such a value is not shown to be false, but it rests on more than the quote beside it. The tiers from 0.70 upward are in order; the two lowest are not: 0.55–0.65 holds mostly regions from coordinates and generated subject identifiers, and the band at 0.50 and below is confirmed from the cited source more often (62.4 %) than the band above it (30.6 %).
