About this page

The catalog curates {{ site.core_fields|length }} core fields ({% for c in site.core_fields %}{{ c }}{% if not loop.last %}, {% endif %}{% endfor %}) and {{ site.key_fields|length }} key fields ({% for c in site.key_fields %}{{ c }}{% if not loop.last %}, {% endif %}{% endfor %}) for every sample — plus the {{ fields|selectattr('infant')|list|length }} birth and feeding fields, which exist only where a project was curated in depth. Fields whose column is not yet in this package are omitted below. Every committed value is one row of catalog_sample_determinations.parquet with a source (archive record · supplementary table · paper text · abstract), a scope (sample or study_all = a cohort-wide statement applied to the study's samples), a confidence and a verbatim evidence quote. Precedence per sample × field: R1 > R2 > R3 > R4 (the infant-extension curation wins for its studies). Coverage below is the share of all {{ stats.n_samples|fmt }} samples with a value.

Confidence by source

Confidence is a discrete engine tier, not a calibrated probability: archive-record parsers 0.7–0.9 by unit certainty; supplementary-table joins 0.8–0.85; two-replicate paper-text statements 0.6–0.7; abstract statements ≤ 0.5. Cohort-wide rows (scope = study_all) are counted per sample they were applied to.
