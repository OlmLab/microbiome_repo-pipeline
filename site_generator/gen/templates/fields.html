Fields

The catalog curates {{ site.core_fields|length }} core fields ({% for c in site.core_fields %}{{ c }}{% if not loop.last %}, {% endif %}{% endfor %}) and {{ site.key_fields|length }} key fields ({% for c in site.key_fields %}{{ c }}{% if not loop.last %}, {% endif %}{% endfor %}) for every sample — tiers defined in config/packs/gut.yaml — plus {{ fields|selectattr('infant')|list|length }} infant-extension fields that exist only where a study was curated in depth for the infant extension. Fields whose column is not yet in this package are omitted below. Every committed value is one row of gut_sample_determinations.parquet with a route (R1 archive attribute · R2 supplementary table · R3 paper full text · R4 abstract / description), a scope (sample or study_all = a cohort-wide statement applied to the study's samples), a confidence and a verbatim evidence quote. Precedence per sample × field: R1 > R2 > R3 > R4 (the infant-extension curation wins for its studies). Coverage below is the share of all {{ stats.n_samples|fmt }} samples with a value.

Confidence by route

Confidence is a discrete engine tier, not a calibrated probability: R1 parsers 0.7–0.9 by unit certainty; R2 table joins 0.8–0.85; R3 two-replicate full-text statements 0.6–0.7; R4 abstract statements ≤ 0.5. Cohort-wide rows (scope = study_all) are counted per sample they were applied to.
