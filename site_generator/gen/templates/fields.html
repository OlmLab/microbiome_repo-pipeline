About this page

The catalog curates {{ site.core_fields|length }} core fields ({% for c in site.core_fields %}{{ c }}{% if not loop.last %}, {% endif %}{% endfor %}) and {{ site.key_fields|length }} key fields ({% for c in site.key_fields %}{{ c }}{% if not loop.last %}, {% endif %}{% endfor %}) for every sample — plus the {{ fields|selectattr('infant')|list|length }} birth and feeding fields, which exist only where a project was curated in depth. Fields whose column is not yet in this package are omitted below. Every committed value carries the source it came from (archive record · supplementary table · paper text · abstract), what it applies to (one sample, or a statement about the whole cohort applied to a project’s samples), a confidence and a verbatim evidence quote. Per sample and field the archive record wins over the supplementary table, then the paper text, then the abstract; the in-depth curation wins for the projects it covers (Where values come from). Health-condition vocabulary

Codes come from archive attributes and supplementary tables — by rule where the wording is unambiguous, otherwise by a language model reading each distinct attribute value — and from papers only when every sequenced person shares the condition. unknown is a code in its own right: it is recorded where a source states that the condition is not known.

Confidence by source

Confidence is a fixed tier per kind of source, not a calibrated probability: a value read from an archive record or a supplementary table scores highest, a statement read twice from a paper lower, a statement from an abstract lowest. The table shows how the values of each source fall into bands. A statement that covers a whole cohort is counted once per sample it was applied to.
