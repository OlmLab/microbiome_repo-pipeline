Registry: every screened shotgun-metagenome study

Is the registry all human? No. The registry holds every shotgun-metagenome study reached by the enumeration — INSDC BioProjects deposited in ENA, NCBI SRA or DDBJ and enumerated through ENA's mirror — and classifies each for human host (registry_studies.host_human): {{ rs.host.yes|fmt }} host human = yes, {{ rs.host.mixed|fmt }} mixed (human and non-human material), {{ rs.host.unknown|fmt }} unknown and {{ rs.host.no|fmt }} no, out of {{ rs.n_studies|fmt }} studies in release {{ site.release_id }}. The {{ rs.n_human|fmt }} human studies (yes + mixed) are the headline number on this site; the explorer below shows them by default and lets you include the unknown and non-human rows.

What a registry row is

Each study carries archive-only metadata (route R1): host, body site(s) anchored to UBERON, life stage(s), assay, access, and the classification stage that produced them, each committed value with an evidence row (labelled source, ≤ 12-word quote). Registry rows are classifications, not inclusions: a study can carry several body sites and life stages; rows at stage pending have not been classified yet. The curated tier goes deeper — per-sample fields recovered from supplementary tables and papers (routes R2–R4) — and is built scope by scope; the catalog (human gut, all ages: {{ rs.n_catalog|fmt }} studies with study pages) is the first curated scope. See Methods › Registry classification for the cascade, the vocabularies and what the confidence means.
