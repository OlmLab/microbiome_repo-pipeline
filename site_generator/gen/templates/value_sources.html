How to read these numbers

Each sample has at most one current value per field. When several sources give a value, the archive record (R1) wins over supplementary tables (R2), then the paper's full text (R3), then the abstract or project description (R4). The counts therefore show what each source adds to the shipped table: a supplementary table that only repeats an archive value is not counted. "Varies by sample" counts values in project × field combinations where the source gives more than one distinct value; the remainder are single statements for a whole project, such as "all participants were recruited in Kenya" or "no antibiotics in the 3 months before sampling". Values of the infant extension are counted by the same routes. 'unknown' values and derived columns (age category, detailed location) are not counted.
